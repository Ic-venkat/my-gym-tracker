# Security Policy

## Supported Versions

We provide security updates for the latest code on the `main` branch:

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |
| < 1.0.0 | :x:                |

---

## Reporting a Vulnerability

The GymTracker team takes privacy and security seriously. All workout data is stored **100% locally on-device** using SQLite/Drift with zero cloud telemetry or external database transmission.

If you believe you have discovered a security vulnerability (such as SQL injection vulnerability, voice command execution risk, or unauthorized local data disclosure):

1. **Do NOT open a public issue.**
2. Send an email to the repository owner at `netaji9850@gmail.com` with:
   - A detailed summary of the vulnerability.
   - Proof of concept (PoC) or reproduction steps.
   - Potential impact on local device storage.
3. You will receive an initial response acknowledging the report within **48 hours**.
4. We ask that you practice responsible disclosure and give us time to remediate the vulnerability before public announcement.
